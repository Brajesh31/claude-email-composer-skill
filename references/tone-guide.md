# Email Tone Guide

| Situation | Tone | Structure |
|---|---|---|
| First professional outreach | Respectful, direct | Context, reason, specific ask |
| Follow-up | Brief, courteous | Prior reference, status question, next step |
| Request for help | Clear, appreciative | Situation, exact request, deadline |
| Apology | Accountable, calm | Acknowledge, impact, corrective action |
| Complaint | Firm, factual | Evidence, impact, requested resolution |
| Thank-you | Specific, sincere | What helped, why it mattered |
| Internal update | Concise, transparent | Status, risks, owner, next action |

## Editing principles
- Prefer concrete verbs and short paragraphs.
- Remove repeated context and generic openings.
- Keep one primary ask per email where possible.
- Do not over-apologize or overstate certainty.
- Use bullets when the recipient must answer several distinct questions.
